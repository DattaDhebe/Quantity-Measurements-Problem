# Quantity Measurements · C#

C# object-oriented exercises for length, volume, weight and temperature conversions with unit tests.

**CSHARP · DOTNET · UNIT-TESTING**

## What is included

| Location | Purpose |
| --- | --- |
| [Quantity Measurements](Quantity%20Measurements) | Length, volume, weight and temperature classes |
| [Quantity Measurements Testing](Quantity%20Measurements%20Testing) | Conversion and comparison tests |
| [Quantity Measurements.sln](Quantity%20Measurements.sln) | Solution |

## Getting started

Use a .NET SDK compatible with the project files:

```bash
dotnet test "Quantity Measurements.sln"
```

Inspect each class and its matching tests to understand the conversion rules.

## Project status

Historical programming exercise. Some constants are simplified; verify conversion precision before reusing the code for real measurements.

Setup commands are documented from the repository structure; execution has not been revalidated as part of this presentation update.
